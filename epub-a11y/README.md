# EPUB 无障碍阅读顺序校修工具

供电子书制作人员校修 EPUB 无障碍阅读顺序的本地 Web 应用。所有处理均在本机完成，不上传任何数据。

## 功能

- **导入解析**：解析 EPUB 的 package(OPF)、spine、导航目录(nav/NCX)与各章 XHTML
- **三栏视图**：章节树（可拖拽）｜排版预览（点击定位节点）｜线性朗读顺序
- **无障碍检查**（编辑后只重跑受影响的检查）：
  - 目录漏项 / 目录与 spine 次序冲突
  - 标题层级跳跃（h1→h3 等）
  - 图片缺少替代文本（装饰图空 alt 视为正确）
  - 语言标签缺失（`<html>` 缺 lang）
  - 重复 ID
  - 失效锚点（含跨章链接）
  - 注释关系图（检查端与工作区共用同一份关系结果）：未声明的引用/注释、
    一号多注、孤立尾注、嵌套注释、回链遗漏（多次引用共用回程只回第一处）、
    跨章错指、跨书目链接、注释环路、尾注区混入普通列表项
  - 复杂表格：caption 缺失、视觉表头仍为 td、scope 与合并结构冲突、
    headers 引用失效/循环、数据格无法关联表头
- **表格工作区**：从问题列表或表格节点打开；网格视图展开 rowspan/colspan 合并关系，
  点选单元格即高亮其表头与覆盖范围；可编辑 caption、切换 th/td、设置 scope、
  点选关联表头（自动生成稳定的 id/headers）；支持批量推断行/列表头
  （与人工指定冲突时保留人工选择并解释原因）；保存前逐格预览屏幕阅读器朗读上下文；
  保存后只重检该张表格
- **注释关系图工作区**：正文引用与脚注/尾注列成可连线的两栏（SVG 贝塞尔曲线），
  点击任一端在排版预览中定位；可把节点标成 noteref/footnote/endnote（非锚点注号
  自动包裹为 `<a>`）、断开/重连连线、为多次引用分别建立回程目标；提交前可逐条
  试听线性朗读顺序。批量套用仅限编号连续且关系唯一的候选；环路、跨书目链接、
  删除仍被引用的注释一律阻止并在问题区列出来源。每次提交保留改前快照，撤销后
  恢复原 ID 与链接；EPUB、变更明细与问题报告使用同一关系结果
- **编辑**：拖拽调整章节/章内节点顺序；增删地标（自动同步 nav 的 landmarks 导航）；修改标题级别、lang、alt
- **撤销**：每次修改均可撤销，变更记录（含已撤销项）完整保留
- **导出**：修正版 EPUB（可重新导入继续校修）、逐项变更记录 CSV、未解决问题报告 HTML
- **内置样例书**：含跨章脚注错指、尾注一号多引/嵌套/环路、装饰图、错序侧栏等典型问题，便于演示与测试

## 安装与启动

```bash
pip install -r requirements.txt
python3 app.py
```

打开浏览器访问 <http://127.0.0.1:5000>，点击「载入样例书」或「导入 EPUB」。

## 运行自测

```bash
python3 selftest.py
```

端到端覆盖：样例书检查项、属性编辑与撤销、节点/章节拖拽排序、地标增删与 nav 同步、
html 根元素语言编辑、表格工作区（网格模型/预览不落盘/推断冲突/稳定 id/单表重检/撤销）、
列表工作区（候选/组合/接续/失败回滚/撤销）、注释关系图（扫描/两栏/连线/回程/
批量唯一/环路与跨书目与删除阻止/快照撤销/导出同源）、
预览与资源、EPUB 导出后重新导入、变更记录与问题报告导出。

## 目录结构

```
app.py            Flask 路由与 API（编辑只重跑受影响检查，撤销栈，表格/列表/注释工作区接口）
epublib.py        EPUB 解析、DOM 路径定位、检查引擎、编辑操作、nav 地标同步、
                  表格网格模型（rowspan/colspan 展开、scope/headers 关联、朗读模拟）
notelib.py        注释关系图（epub:type/ARIA/可见注号扫描、未声明/一号多注/孤立/嵌套/
                  回链/跨章/环路检查、两栏工作区提交、批量唯一候选、快照守恒与撤销）
db.py             SQLite 持久层（书籍/章节/节点/问题/变更记录）
sample_book.py    内置样例书生成器（故意植入各类无障碍问题，含三表、列表、尾注关系图）
selftest.py       端到端回归测试
templates/ static/  原生 HTML/CSS/JS 前端（table.js/list.js/note.js 为三个工作区）
data/             运行期生成：app.db、样例书、各书工作副本 working.epub
```

## 说明

- 编辑直接作用于内存中的文档树，并即时写回 `data/books/<id>/working.epub`，
  服务重启后书籍与修改仍在；撤销历史存于 SQLite。
- DOM 路径（`html[1]/body[1]/section[2]/p[3]`）在前端预览与后端解析间使用同一算法，
  用于「点击预览定位节点」「问题定位」「编辑寻址」。
- 节点移动目前支持章内拖拽（移动到某节点之前或章末）；章节拖拽即 spine 重排。
